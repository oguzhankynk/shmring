# Sending WireForge frames over a message ring

`telemetry_over_ring.cpp` serializes frames generated by
[WireForge](https://github.com/okaynak/wireforge) straight into an `spsc_msg_ring` and decodes them
on the other side with the generated frame decoder.

```sh
pip install /path/to/wireforge
cmake -S . -B build/wireforge -G Ninja -DSHMRING_BUILD_WIREFORGE_EXAMPLE=ON \
  -DWireForge_DIR="$(wireforge cmake-dir)"
cmake --build build/wireforge --target telemetry_over_ring
./build/wireforge/examples/wireforge/telemetry_over_ring
```

The sender calls `reserve(kMaxFrameSize)`, lets `encode_frame` write into the returned view and
commits only the bytes it used (`commit(size)`), so the frame is never copied on the sending side.
